# Итоги интервью и уточнения требований

Рабочая выжимка из актуализированного интервью и последующих согласованных решений. В публичном репозитории представлена **сводка требований**, а не неотредактированная запись интервью.

| Тема | Зафиксированное решение |
|---|---|
| Регистрация | Только по номеру телефона, подтверждение одноразовым SMS-кодом |
| Профиль | ФИО, дата рождения, пароль, ответ на вопрос, который показывает система |
| Аутентификация | Телефон и пароль. SMS в качестве включаемого второго фактора |
| Устройства | До трёх устройств с действующими сессиями. Просмотр и завершение собственных сессий |
| Статусы | `ACTIVE`, `INACTIVE` (после длительного отсутствия входов), `BLOCKED` (администратором) |
| Реактивация | Успешная аутентификация переводит `INACTIVE` в `ACTIVE` |
| Авторизация | `USER` и `ADMIN`, разрешения в модели RBAC |
| Сессия | Завершается после 180 секунд отсутствия активности |
| Внешний вход | Google/VK ID только для ранее привязанной учётной записи |

Детали восстановления пароля описаны в ТЗ и OpenAPI, отдельная UML-диаграмма восстановления не входит в текущий комплект.
