# UML-диаграммы системы аутентификации и авторизации

В разделе представлены UML-диаграммы, описывающие взаимодействие компонентов системы и жизненные циклы учётных записей, пользовательских сессий и токенов.

Диаграммы последовательностей разработаны с использованием PlantUML, диаграммы состояний — в draw.io.

## 1. Sequence Diagram — регистрация пользователя

Диаграмма описывает последовательность взаимодействий при регистрации нового пользователя по номеру телефона.

Рассматриваются отправка и подтверждение SMS-кода, создание учётной записи, назначение роли USER и статуса ACTIVE, создание сессии и выдача токенов.

## 2. Sequence Diagram — аутентификация и авторизация

Диаграмма описывает проверку учётных данных пользователя, дополнительную SMS-аутентификацию, создание сессии и проверку прав доступа при обращении к защищённому API.

## 3. State Diagram — состояния системы

Модель состояний разделена на три части:

- Учётная запись: ACTIVE, INACTIVE, BLOCKED.
- Пользовательская сессия: создание, активность, завершение и истечение.
- Access JWT: выпуск, использование и истечение срока действия.

Разделение необходимо, поскольку изменение состояния сессии или токена не всегда означает изменение статуса учётной записи.

## Исходные файлы

Редактируемые Sequence-диаграммы сохраняются в формате `.puml`, а State Diagram — в формате `.drawio`.

Экспортированные SVG позволяют просматривать диаграммы непосредственно на GitHub.
